# homebrew-tap

Homebrew formulae for [@georgebuilds](https://github.com/georgebuilds) projects.

## Install

```bash
brew tap georgebuilds/tap
```

Then any of:

```bash
brew install carlos    # pure-Go TUI agent
brew install packrat   # TUI archival tool
```

Or as a one-liner:

```bash
brew install georgebuilds/tap/carlos
```

## Formulae

| Formula | Project | Source |
|---------|---------|--------|
| `carlos` | A pure-Go TUI agent with skill induction and sub-agent supervision | [georgebuilds/carlos](https://github.com/georgebuilds/carlos) |
| `packrat` | TUI archival tool | [georgebuilds/packrat](https://github.com/georgebuilds/packrat) |

Formula files in this repo are generated by [goreleaser](https://goreleaser.com) on each upstream release — don't hand-edit `Formula/*.rb`; the next release will overwrite them.
